# Trasfondo

Monitor de recursos para el Workbench de **Commodore Amiga** (AmigaOS 3.x), escrito en
[Dash](https://github.com/FreeMEM/dash): un "top" gráfico pintado en el propio fondo de pantalla, detrás
de los iconos y las ventanas. No se puede pulsar: solo está ahí, de fondo.

Estado: en diseño. Plan en [docs/PLAN.md](docs/PLAN.md).
